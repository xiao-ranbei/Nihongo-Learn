变化规则 例：買う 变化规则 例：食べる 来る（くる） する
基本形／原形
辞書形		 结尾在「う段」假名上 買う 以「る」结尾，且前一个假名在「い段」或「え段」 食べる 来る
（くる）		 する
①ます形 う段 → い段
加ます		 買います 去掉「る」+ ます 食べます 来ます
（きます）		 します
②て形 う、つ、る → って 買って 去掉「る」+ て 食べて 来て
（きて）		 して
む、ぶ、ぬ → んで 飲んで
く → いて 書いて
ぐ → いで 泳いで
す → して 話して
③た形 て形的「て／で」分别改为「た／だ」；例：買って → 買った、飲んで → 飲んだ した
④ない形 う段 → あ段 + ない
「う」→「わ」		 買わない 去掉「る」+ ない 食べない 来ない
（こない）		 しない
⑤命令形 う段 → え段 買え 去掉「る」+ ろ 食べろ 来い
（こい）		 しろ／せよ
⑥意志形 う段 → お段 + う 買おう 去掉「る」+ よう 食べよう 来よう
（こよう）		 しよう
⑦ば形
（假定形）		 う段 → え段 + ば 買えば 去掉「る」+ れば 食べれば 来れば
（くれば）		 すれば
⑧可能形 う段 → え段 + る 買える 去掉「る」+ られる 食べられる 来られる
（こられる）		 できる
⑨被动形 う段 → あ段 + れる 買われる 去掉「る」+ られる 食べられる 来られる
（こられる）		 される
⑩尊敬语 形式同被动形 買われます 形式同被动形 食べられます 来られます されます
⑪使役形 う段 → あ段 + せる 買わせる 去掉「る」+ させる 食べさせる 来させる
（こさせる）		 させる
⑫使役被动 う段 → あ段 + せられる
常缩略为「あ段 + される」		 買わせられる
買わされる		 去掉「る」+ させられる 食べさせられる 来させられる
（こさせられる）		 させられる
⑬禁止形 字典形 + な 買うな 字典形 + な 食べるな 来るな するな
补充 て形例外：行く → 行って。い形容词假定：寒い → 寒ければ；ない → なければ；な形容词、名词 + なら：静かなら、雨なら。
